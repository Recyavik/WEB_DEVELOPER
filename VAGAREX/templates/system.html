API 1T REX — система команд робота

Минимальный набор примитивов, которые понимает реальная плата Rex-Board. Все алгоритмы движения (повороты, обходы, маневры) собираются из этих функций. На вкладке Управление в правой панели Python-код использует ровно эти команды — его можно копировать и запускать на физическом роботе как есть.

Мотор и движение

КомандаОписание
robot.move(power_pct, duration_sec=None) Включает мотор на power_pct процентов мощности (диапазон −100…+100). Положительные значения — вперед, отрицательные — назад. Если задана duration_sec, мотор работает указанное время и сам останавливается. Без аргумента — едет до явного robot.stop() или новой move().
robot.stop() Немедленная остановка двигателя. Сбрасывает текущую скорость в 0.

Калибровка скорости. При 100% мощности робот едет примерно SPEED_CM_PER_S_AT_100 см/с (по умолчанию ≈ 80). Реальное значение зависит от батареи, поверхности, нагрузки — проверьте на своем экземпляре и поправьте константу в настройках.

Руль (Ackermann-сервопривод)

КомандаОписание
robot.set_angle(deg) Поставить серво передних колес на угол deg (диапазон −45…+45°). Положительный угол — поворот направо, отрицательный — налево. Ноль = колеса прямо. Сама ось колес не движется пока мотор стоит — поворот видно только при последующей move().
robot.set_servo_center() Эквивалент robot.set_angle(0). Полезно вызывать в конце маневра, чтобы оставить руль в нейтральном положении.

Геометрия поворота. При полном угле руля и пройденном расстоянии в одну окружность колеса (WHEEL_CIRC_CM) курс робота меняется на HEADING_DEG_PER_ROT градусов (по умолчанию ≈ 25°). Это дает радиус разворота 360 × WHEEL_CIRC_CM / (2π × HEADING_DEG_PER_ROT) ≈ 65 см при стандартных настройках. Минимальный радиус увеличивается с уменьшением угла руля.

Сенсоры

КомандаОписание
robot.get_angle() Возвращает словарь с углами Эйлера от гироскопа MPU: {'X': pitch, 'Y': roll, 'Z': yaw}. Ключ 'Z' — текущий курс робота в градусах (0…359, 0 = направление инициализации). Это основной источник курса для алгоритмов разворота.
robot.get_laser() Возвращает расстояние до препятствия впереди в сантиметрах. None или 0 — нет данных / ничего не видно в зоне действия. Используется в командах «до упора» и для аварийной остановки в режиме «осторожно».
robot.get_color() Цветовой датчик снизу/спереди (если установлен). Возвращает RGB-кортеж или строку с распознанным цветом — используется для слежения по линии.

Одометрия. У 1T REX нет встроенного GPS, позицию (x, y) робота приходится считать самим: курс берем с гироскопа, пройденное расстояние — из power × time. В сгенерированном Python-коде есть класс Odometry, который делает это автоматически — можно копировать на железо как есть.

Световой индикатор (RGB)

КомандаОписание
robot.set_rgb(idx, (r, g, b), count) Зажечь RGB-светодиод. idx — индекс (0 = первый), (r, g, b) — цвет 0…255 на канал, count — сколько светодиодов подряд от idx в эту команду (обычно 1, у адресной ленты — больше). (0, 0, 0) = погасить.

Инициализация и подключение

КомандаОписание
robot.start() Запуск Rex-Board: инициализирует моторы, серво, гироскоп. Вызывается один раз при старте программы (в нашем симуляторе делается автоматически на сервере, в коде не появляется).
robot.enable_mpu() Включает гироскоп / акселерометр. Без этой команды robot.get_angle() может вернуть нули.

Подключение к плате. 1T REX поднимает Wi-Fi и слушает TCP/WebSocket на порту 8765. Первоначальная настройка Wi-Fi — через USB Type-C + утилита server.py из комплекта робота. Адрес и порт реального робота задаются в настройках в разделе «Соединение».

Высокоуровневые функции (Python-преамбула)

В сгенерированном Python-коде уже определены готовые функции, которые собирают сложные алгоритмы из примитивов выше. Их можно копировать на реальный робот как библиотеку.

ФункцияЧто делает
duration_for_distance(distance_cm, power_pct) Сколько секунд держать мотор включенным на заданной мощности, чтобы покрыть указанное расстояние. Опирается на калибровку SPEED_CM_PER_S_AT_100.
class Odometry / odo Простой трекер позиции (x, y, heading) через интегрирование power × time + коррекция курса гироскопом (odo.sync_heading()). Метод odo.move_step(power, duration, steer_deg) надо вызывать ПОСЛЕ каждого robot.move(...).
face_cardinal_cmd(target_deg) 3-дуговой Reeds-Shepp K-turn до указанного курса (forward(α) → backward(β) → forward(α), при условии 2α + β = |Δh| и sin(β/2) = sin(|Δh|/2)/2 робот возвращается в исходную позицию).
goto_cmd(x, y) Перейти в координату. Shortcut: ±30° от курса — едем сразу вперед, ±150° — задом без разворота, иначе K-turn + прямая.
home_cmd() Эквивалент goto_cmd(START_X_CM, START_Y_CM).
follow_path_cmd(points) Pure-pursuit за списком waypoint'ов. Каждые 100 мс находит точку впереди на lookahead_cm, рулит к ней. Используется для безопасного обхода зон в режиме «осторожно».

Минимальный пример программы

import math, time

# Едем 100 см вперед на 40% мощности
duration = 100 / (80 * 40 / 100)   # SPEED_CM_PER_S_AT_100 × power / 100
robot.set_angle(0)
robot.move(40, duration)
robot.stop()

# Поворачиваем руль вправо на максимум и описываем дугу
robot.set_angle(36)
robot.move(40, 2.5)
robot.stop()
robot.set_servo_center()

# Включаем зеленый светодиод
robot.set_rgb(0, (0, 255, 0), 1)
