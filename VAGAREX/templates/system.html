API 1T REX — система команд робота

Это настоящий Python. Программа в редакторе исполняется как обычный Python-код через exec(). Доступны два уровня API: высокоуровневый фасад VEGAREX (robot.forward, robot.goto, robot.arc — то, что пишет автоматически каждая кнопка) и низкоуровневые примитивы реальной платы 1T REX (robot.move, robot.set_angle, robot.get_laser) — для ручного контроля. Один и тот же код работает в симуляторе и на реальном роботе.

Инициализация и системные команды

КомандаОписание
robot.start(interval: int = 10) Запуск Rex-Board и инициализация модулей с автоматическим обновлением данных. interval — период опроса в миллисекундах (по умолчанию 10 мс). Вызывается один раз в начале программы.
robot.enable_mpu(timeout: int | None = None) Включает MPU (гироскоп/акселерометр). После инициализации модуль сам подключается к эфиру. timeout — таймаут инициализации в секундах (default 5). Без этой команды robot.get_angle() может вернуть нули.
robot.set_timeout(timeout: int) Глобальный таймаут для команды robot.move в секундах. Если задан — мотор сам остановится по истечении.
robot.set_multiplexer_channel(value: int) Выбрать канал I²C-мультиплексора (для подключения нескольких датчиков одного типа).
robot.send_command(value: str) Отправка любой raw-команды на плату напрямую. Использовать, если в стандартном API нет нужной обёртки.

Подключение к плате. 1T REX поднимает Wi-Fi и слушает TCP/WebSocket на порту 8765. Первоначальная настройка Wi-Fi — через USB Type-C + утилита server.py из комплекта. Адрес и порт реального робота задаются в настройках.

Мотор и движение

КомандаОписание
robot.move(value: int, timeout: int | None = None) Включает мотор на value процентов мощности (диапазон −100…+100). Положительное — вперёд, отрицательное — назад. timeout — таймаут движения в секундах (опционально). Если задан, мотор сам остановится; иначе крутится до явного robot.stop() или новой move().
Пример: robot.move(100), robot.move(40, 2.5).
robot.invert_move() Переключить инверсию направления. После вызова знак мощности в robot.move меняется на противоположный (полезно, если шасси перевернули или иначе сориентировали).
robot.stop() Немедленная остановка двигателя. Сбрасывает текущую скорость в 0.

Калибровка скорости. При 100% мощности робот едет примерно SPEED_CM_PER_S_AT_100 см/с (по умолчанию ≈ 80). Реальное значение зависит от батареи, поверхности, нагрузки — проверьте на своём экземпляре и поправьте константу в настройках.

Руль (Ackermann-сервопривод)

КомандаОписание
robot.set_angle(value: int) Поставить сервопривод передних колёс на угол value (диапазон −45…+45°). Положительный — направо, отрицательный — налево, 0 — прямо. Сама ось колёс не движется пока мотор стоит — поворот видно только при последующей move().
Пример: robot.set_angle(15).
robot.set_servo_center() Эквивалент robot.set_angle(0). Полезно вызывать в конце маневра, чтобы оставить руль в нейтральном положении.

Геометрия поворота. При полном угле руля и пройденном расстоянии в одну окружность колеса (WHEEL_CIRC_CM) курс робота меняется на HEADING_DEG_PER_ROT градусов (по умолчанию ≈ 25°). Это даёт радиус разворота 360 × WHEEL_CIRC_CM / (2π × HEADING_DEG_PER_ROT) ≈ 65 см при стандартных настройках.

Сенсоры

КомандаОписание
robot.get_angle() Запросить актуальные данные IMU. Формат: { X: float, Y: float, Z: float }.
В редакторе достаточно вызвать без await — он подставляется автоматически для асинхронных методов.
Пример: yaw = robot.get_angle()["Z"] — текущий курс.
robot.get_angles() Получить текущие углы из angles_data (формат тот же: {X, Y, Z}). Углы обновляются автоматически по эфиру после enable_mpu() — быстрее чем get_angle() (последний делает явный запрос).
robot.get_laser() Запросить актуальные данные лазерного дальномера. Формат: int. None или 0 — нет данных (вне зоны действия). Используется в командах «до упора» и для аварийной остановки в режиме «осторожно».
robot.get_color() Запросить актуальные данные датчика цвета (через TCA-мультиплексор). Формат: [{ TCA: int, R: int, G: int, B: int, C: int }] (массив словарей, по одному на каждый канал TCA).
Пример обращения: robot.get_color()["0"]["R"].

Одометрия. У 1T REX нет встроенного GPS, позицию (x, y) приходится считать самим: курс берём с get_angle()['Z'], пройденное расстояние — из power × time. В сгенерированном Python-коде есть класс Odometry, который делает это автоматически — копируется на железо как есть.

RGB-индикатор

КомандаОписание
robot.init_led(address: int, timeout: int | None = None) Инициализировать LED-модуль по адресу. timeout — таймаут инициализации в секундах (default 3).
Пример: robot.init_led(0x10).
robot.leds Список адресов светодиодов (list[int]). Используется для последующего обращения по индексу.
robot.leds[index] Получить адрес конкретного светодиода по индексу.
Пример: robot.leds[0].
robot.leds.bind(value: list[int]) Привязать список адресов светодиодов. Используется при ручном подключении нескольких LED-модулей.
robot.set_rgb(index: int, color: tuple, delay: float = 1.2) Установить цвет RGB-светодиода по индексу. color — (R, G, B) от 0 до 255 с прямой яркостью каналов (255 — горит, 0 — не горит). delay — задержка между установкой каналов в секундах (по умолчанию 1.2; 0.0 = мгновенно).
Внимание: 3-й параметр — не «количество», а именно delay в секундах. Передача 1 вместо 0.0 вызовет fade ≈ 1 секунду.
Пример: robot.set_rgb(0, (255, 0, 0), 1.0).

Звук (пьезо-модуль)

КомандаОписание
robot.init_sound(address: int, timeout: int | None = None) Инициализировать звуковой модуль по адресу. timeout — таймаут инициализации в секундах (default 2).
Пример: robot.init_sound(0x20).
robot.set_sound(value: int) Управление звуком. value — логическая мощность от 0 до 100, которая масштабируется во внутренний диапазон (1–254) и отправляется на плату.
Пример: robot.set_sound(60).

Высокоуровневый фасад VEGAREX

В дополнение к низкоуровневым примитивам выше, в редакторе доступен объект robot с высокоуровневыми методами — это тот же интерфейс, который пишет автоматически каждая кнопка панели управления. Каждый метод знает геометрию робота, считает дистанции и углы, при необходимости задействует A*-планировщик. В осторожном режиме методы автоматически учитывают опасные зоны.

Все методы — синхронные. Под капотом каждый вызов блокирует исполнение программы до окончания манёвра, потом отдаёт управление следующей строке. Можно использовать в if / for / while, читать robot.x, robot.y, robot.heading как обычные переменные.

Состояние робота (свойства)

СвойствоОписание
robot.xТекущая X-координата (см)
robot.yТекущая Y-координата (см)
robot.headingТекущий курс в градусах (0=север, 90=восток, 180=юг, 270=запад)

Базовые движения

МетодЧто делает
robot.forward(distance_cm, speed=None) Едет вперёд на N см. Скорость — % мощности 0..100; None = «по умолчанию из настроек». В Осторожно — клип по препятствию (20 см margin от зоны), длина может быть сокращена.
robot.back(distance_cm, speed=None) Едет назад на N см.
robot.forward_to_wall(speed=None) Едет вперёд до стены или препятствия (по дальномеру).
robot.backward_to_wall(speed=None) Едет назад до стены или препятствия.
robot.wait(seconds) Стоит N секунд (0.1..60), затем продолжает программу.
robot.stop() Аварийная остановка: мотор → 0 мгновенно, программа прерывается на этой строке (RobotInterrupted). Дальнейшие строки кода не выполняются.

Повороты и ориентация

МетодЧто делает
robot.turn_right(angle_deg) Поворот на месте направо на угол в градусах (через K-turn).
robot.turn_left(angle_deg) Поворот на месте налево на угол в градусах.
robot.turn_around(direction=1) Разворот на 180° по дуге. direction: +1 вправо, −1 влево.
robot.kturn(steps=3, direction=1) Разворот на месте за N шагов K-turn. 3 = плавный (≈ 90°), 6 = полный 180°, до 10. Подходит в тесном месте.
robot.face(target_deg) Развернуться лицом к абсолютному курсу N° (3-дуговой K-turn без смещения позиции).
robot.set_course(target_deg) Выйти на курс N° плавной дугой с движением вперёд (позиция меняется).

Дуги и траектории

МетодЧто делает
robot.arc(angle_deg, direction=-1) Дуга на N° при максимальном угле руля из настроек. direction: −1 = против часовой (по умолчанию), +1 = по часовой. arc(360) = полный круг.
robot.figure_eight(direction=-1) Восьмёрка: две дуги по 360° в противоположных направлениях.
robot.spiral(direction=1, outward=True) Спираль 2 оборота. outward=True — раскручивается (угол руля уменьшается), False — скручивается.
robot.bypass(start_dir=1) S-волна для объезда препятствия. +1 = первый отворот вправо, −1 = влево.

Навигация

МетодЧто делает
robot.goto(x, y) Перейти в точку (X, Y). В Осторожно с зонами на пути запускает алгоритм обхода из настроек (Линейный или Ручной).
robot.home() Вернуться в стартовую точку (START_X, START_Y) с центрированием руля перед стартом.

Зоны на карте

МетодЧто делает
robot.load_danger_zones(zones) Установить опасные зоны обстановки из списка [(x, y, radius), ...]. Идемпотентно: повторный вызов с теми же данными даст тот же результат. Используется в авто-генерируемом блоке DANGER_ZONES.
robot.show_danger_zones() Вывести в журнал список активных опасных зон с номерами и координатами, вернуть list[(x, y, r)] для итерации в своей логике.
robot.attention_zone(x, y, radius=None) Доехать до точки (X, Y) и поставить жёлтую зону внимания.
robot.attention_here(radius=None) Поставить жёлтую зону внимания в текущей позиции (без движения).
robot.remove_zone(x, y) Удалить зону (любого типа) в указанной точке. Робот должен находиться внутри удаляемой зоны.
robot.remove_zone_here() Удалить зону под текущей позицией робота.
robot.clear() Очистить превью: убрать все зоны, стереть путь, телепортировать робота в стартовую точку. То же что кнопка ↺ Поле.

Красные опасные зоны программно НЕ создаются. Они — «обстановка», ставятся либо мышью в ⛯ Режиме зон, либо генератором миссий. Программа может только читать DANGER_ZONES и удалять зоны через robot.remove_zone*.

Настройки и индикация

МетодЧто делает
robot.set_default_speed(speed_pct) Изменить скорость по умолчанию для последующих forward/back (только в этой сессии).
robot.set_default_turn_angle(angle_deg) Изменить «максимальный угол руля» (1..45°).
robot.set_rgb(index, color, delay=0.0) Установить цвет LED. color = (R, G, B), значения 0..255.
robot.recharge() Полная зарядка батареи (в симуляторе — мгновенно до 100%).

Низкоуровневый доступ (для опытных)

Тот же фасад предоставляет «сырые» команды платы — те же что в разделах «Мотор», «Руль», «Сенсоры» выше: robot.move(speed_pct, timeout_sec=None), robot.set_angle(angle_deg), robot.set_servo_center(), robot.get_laser(), robot.set_rgb(...). Используются когда нужен ручной контроль мотора и руля по тактам — например в своей реализации алгоритма следования.

Минимальный пример программы (фасад VEGAREX)

Самый частый сценарий: фасад robot.X(...) делает всю геометрию за тебя. Это обычный Python — можно сразу нажимать ▶, исполнится через exec(). 

# Едем 100 см вперёд на 40% мощности
robot.forward(100, speed=40)

# Развернуться лицом к востоку (на месте, 90°)
robot.face(90)

# Дуга 180° по часовой стрелке (полукруг)
robot.arc(180, +1)

# Зажечь зелёный светодиод
robot.set_rgb(0, (0, 255, 0), 0.0)

Все параметры фасада — в «человеческих» единицах: сантиметры, градусы, проценты мощности. Никаких миллисекунд и долей оборота.

Пример с зонами и условиями

Программа читает DANGER_ZONES (автоблок преамбулы), выводит их в журнал, делает goto к точке через A* (если в Осторожно), и при достижении проверяет позицию через robot.x / robot.y. 

# Показать в журнале все опасные зоны и пересчитать их.
zones = robot.show_danger_zones()
print(f'Активно зон: {len(zones)}')

# Идём в точку (100, 50) — в Осторожно с зоной на пути сработает
# выбранный в настройках алгоритм обхода (Линейный / Ручной).
robot.goto(100, 50)

# Проверяем — реально ли доехали (вдруг manual handoff не дал пройти).
err = ((robot.x - 100) ** 2 + (robot.y - 50) ** 2) ** 0.5
if err < 10:
    print('✓ В точке')
    robot.set_rgb(0, (0, 255, 0), 0.0)
else:
    print(f'⚠ Промах на {err:.0f} см')
    robot.set_rgb(0, (255, 0, 0), 0.0)

# Возврат домой
robot.home()

Расширенный пример (низкоуровневые примитивы 1T REX)

Для опытных: полная мини-миссия «прибыл — осмотрелся — поработал — вернулся», на низкоуровневых примитивах реальной платы — инициализация, мотор/руль, дальномер, гироскоп, цветовой датчик, RGB-индикатор, звук, пауза. Без высокоуровневых обёрток фасада VEGAREX. Этот код можно копировать в среду 1T REX как есть. 

import math, time

# ── 1. Инициализация платы ──────────────────────────────────────────────
robot.start(interval=10)                     # запуск с опросом 10 мс
robot.enable_mpu()                           # включаем гироскоп / акселерометр
robot.init_led(0x10)                         # инициализируем LED-модуль
robot.init_sound(0x20)                       # звуковой модуль
robot.set_servo_center()                     # руль в нейтраль
robot.set_rgb(0, (255, 200, 0), 0.0)         # жёлтый = «готов к работе»
time.sleep(0.5)

# ── 2. Запоминаем стартовый курс (потом вернёмся на него) ───────────────
start_yaw = robot.get_angle()["Z"]           # курс с гироскопа в градусах
print("Стартовый курс:", start_yaw)

# ── 3. Едем вперёд до препятствия с проверкой дальномера ────────────────
robot.set_rgb(0, (0, 255, 0), 0.0)           # зелёный = «движение»
robot.set_angle(0)                           # руль прямо
robot.move(50)                               # вперёд 50% без timeout
while True:
    dist = robot.get_laser()                 # дальность до препятствия
    if dist is not None and dist <= 20:      # ближе 20 см — стоп!
        break
    time.sleep(0.05)
robot.stop()
robot.set_rgb(0, (255, 0, 0), 0.0)           # красный = «препятствие!»
robot.set_sound(40)                          # короткий гудок
time.sleep(0.3)
robot.set_sound(0)

# ── 4. Считываем цвет под роботом ───────────────────────────────────────
color_data = robot.get_color()               # массив словарей TCA/R/G/B/C
print("Цвет канала 0:", color_data["0"]["R"], color_data["0"]["G"], color_data["0"]["B"])

# ── 5. Объезд препятствия — S-волна 4 четверть-дугами ───────────────────
robot.set_rgb(0, (0, 100, 255), 0.0)         # синий = «маневр объезда»
QUARTER_SEC = 0.5
for phase in range(4):
    sign = +1 if phase in (0, 3) else -1
    robot.set_angle(sign * 36)
    robot.move(40, QUARTER_SEC)
robot.stop()
robot.set_servo_center()

# ── 6. Едем 1 метр прямо ────────────────────────────────────────────────
SPEED_CM_S_100 = 80.0
power = 40
distance = 100
secs = distance / (SPEED_CM_S_100 * power / 100)   # ≈ 3.13 с
robot.set_angle(0)
robot.move(power, secs)
robot.stop()

# ── 7. Полный круг (одна непрерывная дуга 360°) ────────────────────────
robot.set_angle(-36)
robot.move(40, 4.0)
robot.stop()
robot.set_servo_center()

# ── 8. Возвращаемся на исходный курс мелкими дугами ────────────────────
target_yaw = start_yaw
while True:
    cur = robot.get_angle()["Z"]
    diff = ((target_yaw - cur + 540) % 360) - 180
    if abs(diff) < 3.0:
        break
    direction = +1 if diff > 0 else -1
    robot.set_angle(direction * 36)
    robot.move(direction * 30, 0.3)
    time.sleep(0.1)
robot.stop()
robot.set_servo_center()

# ── 9. Задом 30 см ──────────────────────────────────────────────────────
secs = 30 / (SPEED_CM_S_100 * power / 100)
robot.move(-power, secs)
robot.stop()

# ── 10. Финиш: мигаем зелёным 3 раза, гасим ─────────────────────────────
for _ in range(3):
    robot.set_rgb(0, (0, 255, 0), 0.0)
    time.sleep(0.3)
    robot.set_rgb(0, (0, 0, 0), 0.0)
    time.sleep(0.3)
robot.set_rgb(0, (0, 0, 0), 0.0)

Что использовано: robot.start (с interval), robot.enable_mpu, robot.init_led, robot.init_sound, robot.set_angle, robot.set_servo_center, robot.move (с timeout и без; вперёд и назад), robot.stop, robot.get_angle (yaw), robot.get_laser, robot.get_color (с разбором канала), robot.set_rgb (мгновенный delay=0.0), robot.set_sound, time.sleep.
