API 1T REX — система команд робота

Полный список базовых примитивов, которые понимает реальная плата Rex-Board. Все наши алгоритмы движения (повороты, обходы, маневры) собираются ТОЛЬКО из этих функций. В сгенерированном Python-коде используется ровно этот API — его можно копировать и запускать на физическом роботе как есть.

Инициализация и системные команды

КомандаОписание
robot.start(interval: int = 10) Запуск Rex-Board и инициализация модулей с автоматическим обновлением данных. interval — период опроса в миллисекундах (по умолчанию 10 мс). Вызывается один раз в начале программы.
robot.enable_mpu(timeout: int | None = None) Включает MPU (гироскоп/акселерометр). После инициализации модуль сам подключается к эфиру. timeout — таймаут инициализации в секундах (default 5). Без этой команды robot.get_angle() может вернуть нули.
robot.set_timeout(timeout: int) Глобальный таймаут для команды robot.move в секундах. Если задан — мотор сам остановится по истечении.
robot.set_multiplexer_channel(value: int) Выбрать канал I²C-мультиплексора (для подключения нескольких датчиков одного типа).
robot.send_command(value: str) Отправка любой raw-команды на плату напрямую. Использовать, если в стандартном API нет нужной обёртки.

Подключение к плате. 1T REX поднимает Wi-Fi и слушает TCP/WebSocket на порту 8765. Первоначальная настройка Wi-Fi — через USB Type-C + утилита server.py из комплекта. Адрес и порт реального робота задаются в настройках.

Мотор и движение

КомандаОписание
robot.move(value: int, timeout: int | None = None) Включает мотор на value процентов мощности (диапазон −100…+100). Положительное — вперёд, отрицательное — назад. timeout — таймаут движения в секундах (опционально). Если задан, мотор сам остановится; иначе крутится до явного robot.stop() или новой move().
Пример: robot.move(100), robot.move(40, 2.5).
robot.invert_move() Переключить инверсию направления. После вызова знак мощности в robot.move меняется на противоположный (полезно, если шасси перевернули или иначе сориентировали).
robot.stop() Немедленная остановка двигателя. Сбрасывает текущую скорость в 0.

Калибровка скорости. При 100% мощности робот едет примерно SPEED_CM_PER_S_AT_100 см/с (по умолчанию ≈ 80). Реальное значение зависит от батареи, поверхности, нагрузки — проверьте на своём экземпляре и поправьте константу в настройках.

Руль (Ackermann-сервопривод)

КомандаОписание
robot.set_angle(value: int) Поставить сервопривод передних колёс на угол value (диапазон −45…+45°). Положительный — направо, отрицательный — налево, 0 — прямо. Сама ось колёс не движется пока мотор стоит — поворот видно только при последующей move().
Пример: robot.set_angle(15).
robot.set_servo_center() Эквивалент robot.set_angle(0). Полезно вызывать в конце маневра, чтобы оставить руль в нейтральном положении.

Геометрия поворота. При полном угле руля и пройденном расстоянии в одну окружность колеса (WHEEL_CIRC_CM) курс робота меняется на HEADING_DEG_PER_ROT градусов (по умолчанию ≈ 25°). Это даёт радиус разворота 360 × WHEEL_CIRC_CM / (2π × HEADING_DEG_PER_ROT) ≈ 65 см при стандартных настройках.

Сенсоры

КомандаОписание
robot.get_angle() Запросить актуальные данные IMU. Формат: { X: float, Y: float, Z: float }.
В редакторе достаточно вызвать без await — он подставляется автоматически для асинхронных методов.
Пример: yaw = robot.get_angle()["Z"] — текущий курс.
robot.get_angles() Получить текущие углы из angles_data (формат тот же: {X, Y, Z}). Углы обновляются автоматически по эфиру после enable_mpu() — быстрее чем get_angle() (последний делает явный запрос).
robot.get_laser() Запросить актуальные данные лазерного дальномера. Формат: int. None или 0 — нет данных (вне зоны действия). Используется в командах «до упора» и для аварийной остановки в режиме «осторожно».
robot.get_color() Запросить актуальные данные датчика цвета (через TCA-мультиплексор). Формат: [{ TCA: int, R: int, G: int, B: int, C: int }] (массив словарей, по одному на каждый канал TCA).
Пример обращения: robot.get_color()["0"]["R"].

Одометрия. У 1T REX нет встроенного GPS, позицию (x, y) приходится считать самим: курс берём с get_angle()['Z'], пройденное расстояние — из power × time. В сгенерированном Python-коде есть класс Odometry, который делает это автоматически — копируется на железо как есть.

RGB-индикатор

КомандаОписание
robot.init_led(address: int, timeout: int | None = None) Инициализировать LED-модуль по адресу. timeout — таймаут инициализации в секундах (default 3).
Пример: robot.init_led(0x10).
robot.leds Список адресов светодиодов (list[int]). Используется для последующего обращения по индексу.
robot.leds[index] Получить адрес конкретного светодиода по индексу.
Пример: robot.leds[0].
robot.leds.bind(value: list[int]) Привязать список адресов светодиодов. Используется при ручном подключении нескольких LED-модулей.
robot.set_rgb(index: int, color: tuple, delay: float = 1.2) Установить цвет RGB-светодиода по индексу. color — (R, G, B) от 0 до 255 с прямой яркостью каналов (255 — горит, 0 — не горит). delay — задержка между установкой каналов в секундах (по умолчанию 1.2; 0.0 = мгновенно).
Внимание: 3-й параметр — не «количество», а именно delay в секундах. Передача 1 вместо 0.0 вызовет fade ≈ 1 секунду.
Пример: robot.set_rgb(0, (255, 0, 0), 1.0).

Звук (пьезо-модуль)

КомандаОписание
robot.init_sound(address: int, timeout: int | None = None) Инициализировать звуковой модуль по адресу. timeout — таймаут инициализации в секундах (default 2).
Пример: robot.init_sound(0x20).
robot.set_sound(value: int) Управление звуком. value — логическая мощность от 0 до 100, которая масштабируется во внутренний диапазон (1–254) и отправляется на плату.
Пример: robot.set_sound(60).

Наши готовые функции (поверх базового API)

В сгенерированном Python-коде уже определены готовые функции, которые собирают сложные алгоритмы из примитивов выше. Их можно копировать на реальный робот как библиотеку — каждая функция написана только через robot.* примитивы, ничего внешнего не требуется. Подробное описание с диаграммами — в разделе Справка → Маневры.

Утилиты

ФункцияЧто делает
duration(distance_cm, power_pct) Сколько секунд держать мотор включённым на заданной мощности, чтобы покрыть указанное расстояние. Опирается на калибровку SPEED_CM_PER_S_AT_100. Возвращаемое число передаётся вторым аргументом в robot.move.
class Odometry / odo Простой трекер позиции (x, y, heading) через интегрирование power × time + коррекция курса гироскопом (odo.sync_heading() читает robot.get_angle()['Z']). Метод odo.move_step(power, duration, steer_deg) надо вызывать ПОСЛЕ каждого robot.move(...).

Базовые движения

ФункцияЧто делает
to_wall_cmd(power_pct=DEFAULT_SPEED, stop_margin_cm=15) Движение вперёд до препятствия по дальномеру. Останавливается когда robot.get_laser() ≤ stop_margin_cm.
back_to_wall_cmd(power_pct=DEFAULT_SPEED, stop_margin_cm=15) Зеркальная функция — движение назад до препятствия (если есть задний дальномер; иначе по одометрии).

Развороты и ориентация

ФункцияЧто делает
turn_around_cmd(direction=1, power_pct=DEFAULT_SPEED) Разворот на 180° одной K-turn-парой (вперёд по дуге + назад по зеркальной дуге). Робот возвращается ≈ в исходную точку. direction = +1 направо, −1 налево.
kturn_cmd(steps, power_pct=DEFAULT_SPEED) Разворот на месте N парами «вперёд+право → назад+лево» (≈ 30°/пара). 6 пар = 180°. Удобен в тесном пространстве.
face_cmd(target_deg, power_pct=DEFAULT_SPEED) Повернуться лицом к любому курсу 0–359° на месте (3-дуговой K-turn по формулам Reeds-Shepp). Используется и для сторон света (face_cmd(0) = север, 90 = восток и т.д.), и для произвольных углов (голос: «Вега поверни на 70»).
course_cmd(target_deg, power_pct=DEFAULT_SPEED) Выйти на нужный курс плавной дугой на ходу (с движением вперёд). P-регулятор по углу руля. В отличие от face_cmd — позиция меняется, робот не стоит на месте.

Маневры по траектории

ФункцияЧто делает
circle_cmd(direction=-1, power_pct=DEFAULT_SPEED, full_turn_sec=4.0) Один полный круг при максимальном угле руля. По умолчанию CCW (против часовой); direction=+1 — по часовой.
figure_eight_cmd(direction=-1, power_pct=DEFAULT_SPEED, full_turn_sec=4.0) Восьмёрка: первый круг при руле direction × max, второй — в зеркало.
spiral_cmd(direction=-1, ..., steer_from=36, steer_to=24, turns=2, micro_sec=0.3) Архимедова спираль: за каждый микро-шаг угол руля меняется линейно от steer_from до steer_to.
bypass_cmd(start_dir=1, max_steer=36, power_pct=DEFAULT_SPEED, quarter_sec=0.5) Объезд препятствия S-волной из 4 четверть-дуг.

Навигация по координатам

ФункцияЧто делает
goto_cmd(target_x, target_y, power_pct=DEFAULT_SPEED, tolerance_cm=5) Перейти в координату. Shortcut: |bearing| ≤ 30° — едем сразу вперёд, ≥ 150° — задом без разворота, иначе K-turn + прямая. Closed-loop коррекция курса по гироскопу.
home_cmd(power_pct=DEFAULT_SPEED) Возврат в стартовую точку. Эквивалент goto_cmd(START_X, START_Y).
drive_loop(target_x, target_y, power_pct, tolerance_cm, step_sec=0.1, kp=0.7) Прямой проезд к точке короткими шагами с подруливанием по гироскопу на каждом такте.
follow_path_cmd(points, power_pct=DEFAULT_SPEED, lookahead_cm=None, tolerance_cm=5) Pure-pursuit за списком waypoint'ов. Используется для безопасного обхода зон в режиме «осторожно».

Зоны обстановки

ФункцияЧто делает
mark_danger_cmd(x, y, radius) Отметить опасную (красную) зону по координатам, без движения робота.
danger_here_cmd() Отметить опасную зону под текущей позицией робота (берёт odo.x, odo.y из нашей одометрии — у 1T REX нет встроенного GPS).
attention_zone_cmd(target_x, target_y, radius) Доехать в точку (через goto_cmd) и пометить там зону внимания (жёлтая пунктирная — часть алгоритма).
remove_zone_cmd(x, y) Удалить зону любого типа, в которую попадает точка.
clear_here_cmd() Удалить зону под текущей позицией робота (по одометрии).

Минимальный пример программы

import math, time

# Едем 100 см вперёд на 40% мощности
duration = 100 / (80 * 40 / 100)   # SPEED_CM_PER_S_AT_100 × power / 100 = 3.13 с
robot.set_angle(0)
robot.move(40, duration)
robot.stop()

# Поворачиваем руль вправо на максимум и описываем дугу
robot.set_angle(36)
robot.move(40, 2.5)
robot.stop()
robot.set_servo_center()

# Включаем зелёный светодиод мгновенно (delay=0)
robot.set_rgb(0, (0, 255, 0), 0.0)

Расширенный пример программы

Полная мини-миссия «прибыл — осмотрелся — поработал — вернулся», использующая максимальный ассортимент robot.*-примитивов: инициализация, мотор/руль, дальномер, гироскоп, цветовой датчик, RGB-индикатор, звук, пауза. Без высокоуровневых обёрток — только примитивы из этого справочника. 

import math, time

# ── 1. Инициализация платы ──────────────────────────────────────────────
robot.start(interval=10)                     # запуск с опросом 10 мс
robot.enable_mpu()                           # включаем гироскоп / акселерометр
robot.init_led(0x10)                         # инициализируем LED-модуль
robot.init_sound(0x20)                       # звуковой модуль
robot.set_servo_center()                     # руль в нейтраль
robot.set_rgb(0, (255, 200, 0), 0.0)         # жёлтый = «готов к работе»
time.sleep(0.5)

# ── 2. Запоминаем стартовый курс (потом вернёмся на него) ───────────────
start_yaw = robot.get_angle()["Z"]           # курс с гироскопа в градусах
print("Стартовый курс:", start_yaw)

# ── 3. Едем вперёд до препятствия с проверкой дальномера ────────────────
robot.set_rgb(0, (0, 255, 0), 0.0)           # зелёный = «движение»
robot.set_angle(0)                           # руль прямо
robot.move(50)                               # вперёд 50% без timeout
while True:
    dist = robot.get_laser()                 # дальность до препятствия
    if dist is not None and dist <= 20:      # ближе 20 см — стоп!
        break
    time.sleep(0.05)
robot.stop()
robot.set_rgb(0, (255, 0, 0), 0.0)           # красный = «препятствие!»
robot.set_sound(40)                          # короткий гудок
time.sleep(0.3)
robot.set_sound(0)

# ── 4. Считываем цвет под роботом ───────────────────────────────────────
color_data = robot.get_color()               # массив словарей TCA/R/G/B/C
print("Цвет канала 0:", color_data["0"]["R"], color_data["0"]["G"], color_data["0"]["B"])

# ── 5. Объезд препятствия — S-волна 4 четверть-дугами ───────────────────
robot.set_rgb(0, (0, 100, 255), 0.0)         # синий = «маневр объезда»
QUARTER_SEC = 0.5
for phase in range(4):
    sign = +1 if phase in (0, 3) else -1
    robot.set_angle(sign * 36)
    robot.move(40, QUARTER_SEC)
robot.stop()
robot.set_servo_center()

# ── 6. Едем 1 метр прямо ────────────────────────────────────────────────
SPEED_CM_S_100 = 80.0
power = 40
distance = 100
secs = distance / (SPEED_CM_S_100 * power / 100)   # ≈ 3.13 с
robot.set_angle(0)
robot.move(power, secs)
robot.stop()

# ── 7. Полный круг (одна непрерывная дуга 360°) ────────────────────────
robot.set_angle(-36)
robot.move(40, 4.0)
robot.stop()
robot.set_servo_center()

# ── 8. Возвращаемся на исходный курс мелкими дугами ────────────────────
target_yaw = start_yaw
while True:
    cur = robot.get_angle()["Z"]
    diff = ((target_yaw - cur + 540) % 360) - 180
    if abs(diff) < 3.0:
        break
    direction = +1 if diff > 0 else -1
    robot.set_angle(direction * 36)
    robot.move(direction * 30, 0.3)
    time.sleep(0.1)
robot.stop()
robot.set_servo_center()

# ── 9. Задом 30 см ──────────────────────────────────────────────────────
secs = 30 / (SPEED_CM_S_100 * power / 100)
robot.move(-power, secs)
robot.stop()

# ── 10. Финиш: мигаем зелёным 3 раза, гасим ─────────────────────────────
for _ in range(3):
    robot.set_rgb(0, (0, 255, 0), 0.0)
    time.sleep(0.3)
    robot.set_rgb(0, (0, 0, 0), 0.0)
    time.sleep(0.3)
robot.set_rgb(0, (0, 0, 0), 0.0)

Что использовано: robot.start (с interval), robot.enable_mpu, robot.init_led, robot.init_sound, robot.set_angle, robot.set_servo_center, robot.move (с timeout и без; вперёд и назад), robot.stop, robot.get_angle (yaw), robot.get_laser, robot.get_color (с разбором канала), robot.set_rgb (мгновенный delay=0.0), robot.set_sound, time.sleep.
