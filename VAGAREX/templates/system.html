API 1T REX — команды робота

Это настоящий Python. Программа в редакторе исполняется кнопкой ▶ как обычный код через exec(). Управление роботом — через объект robot: каждый его метод знает геометрию робота, считает дистанции и углы. Все методы синхронные — вызов блокирует программу до конца манёвра, потом отдаёт управление следующей строке. То, что пишет в код каждая кнопка панели — это вызовы того же robot.X(...).

Что доступно в программе

  • robot — объект управления роботом (методы — в таблицах ниже).
  • import math, time, random — только эти модули; os, open, eval и прочее запрещены (sandbox).
  • print(...) — выводит в журнал (не в консоль). Удобно для отладки.
  • Конструкции Python: if, for, while, функции, списки — всё работает.
  • Константы преамбулы: START_X, START_Y, START_HEADING_DEG — стартовая точка; OBSTACLES — препятствия; DANGER_ZONES — список опасных зон; LIGHT_* — параметры RGB.

Единицы — «человеческие»: расстояния в сантиметрах, углы и курс в градусах, мощность мотора в процентах. Курс: 0° = север (вверх), 90° = восток, 180° = юг, 270° = запад.

Состояние робота (свойства для чтения)

СвойствоОписание
robot.xТекущая X-координата носа робота, см
robot.yТекущая Y-координата носа робота, см
robot.headingТекущий курс, градусы (0 = север, 90 = восток, 180 = юг, 270 = запад)

Свойства читаются как обычные переменные — годятся для if и циклов: if robot.y > 100: ..., print(f'X={robot.x:.0f}, курс={robot.heading:.0f}').

Движение

МетодЧто делает
robot.forward(distance_cm, speed=None) Едет вперёд на N см. speed — % мощности 30..100 (меньшие значения клэмпаются до 30 с предупреждением — двигатель не тянет ниже); None = скорость по умолчанию из настроек. Если впереди препятствие — остановится раньше, а команда в коде сократится до фактической дистанции.
robot.back(distance_cm, speed=None) Едет назад на N см. Препятствия сзади учитываются так же.
robot.forward_to_wall(speed=None) Едет вперёд до ближайшей стены или препятствия (по дальномеру).
robot.backward_to_wall(speed=None) Едет задом до ближайшего препятствия за роботом.
robot.wait(seconds) Стоит на месте N секунд (0.1..60), затем продолжает программу.
robot.stop() Аварийная остановка: мотор → 0 мгновенно, программа прерывается на этой строке — дальнейшие строки кода не выполняются (как кнопка ■ СТОП).

Повороты и ориентация

МетодЧто делает
robot.turn_right(angle_deg) Поворот на месте направо на N° (3-дуговой K-turn, без смещения).
robot.turn_left(angle_deg) Поворот на месте налево на N°.
robot.face(target_deg) Развернуться лицом к абсолютному курсу N° на месте.
robot.turn_around(direction=1) Разворот на 180°. direction: +1 вправо, −1 влево.
robot.kturn(steps=3, direction=1) Разворот на 180° на месте за N приёмов K-turn (1..10). Больше шагов — компактнее манёвр, для тесного пространства.
robot.set_course(target_deg) Выйти на курс N° плавной дугой с движением вперёд (в отличие от face — позиция меняется).

Развороты turn_* / face / turn_around / kturn сами выбирают способ по доступному месту: хватает места — обычный K-turn; тесно — мелкий многошаговый разворот с отъездом; совсем негде — стоп с сообщением. Учитываются стены и зоны-препятствия.

Дуги и траектории

МетодЧто делает
robot.arc(angle_deg, direction=-1) Дуга на N° при максимальном угле руля из настроек. direction: −1 = против часовой (по умолчанию), +1 = по часовой. arc(360) = полный круг.
robot.figure_eight(direction=-1) Восьмёрка: две дуги по 360° в противоположных направлениях.
robot.spiral(direction=1, outward=True) Спираль ≈ 2 оборота. outward=True — раскручивается (радиус растёт), False — скручивается.
robot.bypass(start_dir=1) S-волна для объезда препятствия: +1 = первый отворот вправо, −1 = влево. Возвращается на исходный курс.

Навигация по координатам

МетодЧто делает
robot.goto(x, y) Перейти в точку (X, Y): поворот к цели + прямая. Едет по прямой — если на пути зона-препятствие, остановится у неё. Объезд зон — задача autopilot.
robot.home() Вернуться в стартовую точку (START_X, START_Y).
robot.autopilot(x, y) Построить маршрут к (X, Y) в обход препятствий (A*-планировщик) и проехать его. Объезжаются стены и зоны, отмеченные в «Препятствиях». Алгоритм (ломаная / сглаженная) — из настроек. Пройденные участки дописываются в код.
robot.curve(route) Плавно проехать по кривой через опорные точки [(x, y), ...] — одна непрерывная дуга с подруливанием на ходу. Этим автопилот в сглаженном режиме записывает маршрут; повторный ▶ воспроизводит дугу.

Зоны на карте

МетодЧто делает
robot.load_danger_zones(zones) Установить опасные зоны обстановки из списка [(x, y, radius), ...]. Идемпотентно. Используется в авто-блоке DANGER_ZONES преамбулы.
robot.show_danger_zones() Вывести в журнал активные опасные зоны и вернуть list[(x, y, r)] для итерации в своей логике.
robot.attention_zone(x, y, radius=None) Поставить жёлтую зону внимания в точке (X, Y).
robot.attention_here(radius=None) Поставить жёлтую зону внимания в текущей позиции робота.
robot.remove_zone(x, y) Удалить зону в точке (X, Y). Робот должен быть внутри неё.
robot.remove_zone_here() Удалить зону под текущей позицией робота.
robot.clear() Очистить поле: убрать зоны и путь, вернуть робота в стартовую точку (как кнопка ↺ Поле).

Красные опасные зоны программно не создаются. Это «обстановка» — ставятся мышью в режиме «⛯ Обстановка» либо генератором миссий. Программа может читать DANGER_ZONES и удалять зоны через remove_zone*. Жёлтые зоны внимания — создаются программой (attention_*).

Настройки и индикация

МетодЧто делает
robot.set_default_speed(speed_pct) Скорость по умолчанию для последующих forward / back без явного speed= (на эту сессию). Минимум — 30%; меньшие значения автоматически клэмпаются с предупреждением в журнал (двигатель не тянет ниже).
robot.set_default_turn_angle(angle_deg) «Максимальный угол руля» (1..45°) — влияет на радиус дуг.
robot.set_rgb(index, color, delay=0.0) Зажечь RGB-светодиод. color = (R, G, B), 0..255. delay — задержка между каналами в секундах (0.0 = мгновенно).
robot.recharge() Зарядить батарею (в симуляторе — мгновенно до 100%).

Ручное управление мотором и рулём (для опытных)

Когда высокоуровневых команд не хватает (например, своя реализация движения по дуге с ручным таймингом) — мотор и руль можно крутить напрямую. Эти методы повторяют примитивы реальной платы 1T REX.

МетодЧто делает
robot.move(speed_pct, timeout_sec=None) Подать на мотор мощность −100..+100 (− = назад). Без timeout_sec — крутит до move(0) / stop(); с таймаутом — едет это время и встаёт.
robot.set_angle(angle_deg) Угол руля −45..+45° (0 = прямо, + = вправо). Поворот виден только при движении.
robot.set_servo_center() Поставить руль в 0° (то же, что set_angle(0)).

Калибровка. При 100% мощности робот едет ≈ SPEED_CM_PER_S_AT_100 см/с (по умолчанию 80). При полном угле руля за один оборот колеса курс меняется на HEADING_DEG_PER_ROT° (≈ 25). Значения — в настройках.

Пример 1 — базовые команды

Самый частый сценарий: robot.X(...) делает всю геометрию за тебя. Это обычный Python — жми ▶, исполнится через exec(). 

# Едем 100 см вперёд на 40% мощности
robot.forward(100, speed=40)

# Развернуться лицом к востоку (на месте)
robot.face(90)

# Дуга 180° по часовой стрелке (полукруг)
robot.arc(180, +1)

# Зажечь зелёный светодиод
robot.set_rgb(0, (0, 255, 0), 0.0)

Пример 2 — зоны, условия, автопилот

Программа читает DANGER_ZONES из преамбулы, объезжает зоны автопилотом и проверяет результат через robot.x/y. 

# Показать в журнале все опасные зоны
zones = robot.show_danger_zones()
print(f'Активно зон: {len(zones)}')

# Доехать до (100, 150) в обход препятствий
robot.autopilot(100, 150)

# Проверяем — реально ли доехали
err = ((robot.x - 100) ** 2 + (robot.y - 150) ** 2) ** 0.5
if err < 12:
    print('✓ В точке')
    robot.set_rgb(0, (0, 255, 0), 0.0)
else:
    print(f'⚠ Промах на {err:.0f} см')
    robot.set_rgb(0, (255, 0, 0), 0.0)

robot.home()

Пример 3 — цикл и ручное управление

Цикл for + ручной мотор/руль. Квадрат стороной 60 см, затем своя дуга на низкоуровневых move / set_angle. 

import time

# Квадрат: 4 стороны по 60 см с поворотом на 90°
for i in range(4):
    robot.forward(60)
    robot.turn_right(90)

# Своя дуга вручную: руль вправо, мотор 2 секунды
robot.set_angle(36)
robot.move(40, timeout_sec=2.0)
robot.set_servo_center()

# Помигать синим 3 раза
for _ in range(3):
    robot.set_rgb(0, (0, 100, 255), 0.0)
    time.sleep(0.3)
    robot.set_rgb(0, (0, 0, 0), 0.0)
    time.sleep(0.3)

Подсказка: набери robot. в редакторе — выпадет список методов с описанием и сигнатурой.
