API 1T REX — система команд робота

Минимальный набор примитивов, которые понимает реальная плата Rex-Board. Все алгоритмы движения (повороты, обходы, маневры) собираются из этих функций. На вкладке Управление в правой панели Python-код использует ровно эти команды — его можно копировать и запускать на физическом роботе как есть.

Мотор и движение

КомандаОписание
robot.move(power_pct, duration_sec=None) Включает мотор на power_pct процентов мощности (диапазон −100…+100). Положительные значения — вперед, отрицательные — назад. Если задана duration_sec, мотор работает указанное время и сам останавливается. Без аргумента — едет до явного robot.stop() или новой move().
robot.stop() Немедленная остановка двигателя. Сбрасывает текущую скорость в 0.

Калибровка скорости. При 100% мощности робот едет примерно SPEED_CM_PER_S_AT_100 см/с (по умолчанию ≈ 80). Реальное значение зависит от батареи, поверхности, нагрузки — проверьте на своем экземпляре и поправьте константу в настройках.

Руль (Ackermann-сервопривод)

КомандаОписание
robot.set_angle(deg) Поставить серво передних колес на угол deg (диапазон −45…+45°). Положительный угол — поворот направо, отрицательный — налево. Ноль = колеса прямо. Сама ось колес не движется пока мотор стоит — поворот видно только при последующей move().
robot.set_servo_center() Эквивалент robot.set_angle(0). Полезно вызывать в конце маневра, чтобы оставить руль в нейтральном положении.

Геометрия поворота. При полном угле руля и пройденном расстоянии в одну окружность колеса (WHEEL_CIRC_CM) курс робота меняется на HEADING_DEG_PER_ROT градусов (по умолчанию ≈ 25°). Это дает радиус разворота 360 × WHEEL_CIRC_CM / (2π × HEADING_DEG_PER_ROT) ≈ 65 см при стандартных настройках. Минимальный радиус увеличивается с уменьшением угла руля.

Сенсоры

КомандаОписание
robot.get_angle() Возвращает словарь с углами Эйлера от гироскопа MPU: {'X': pitch, 'Y': roll, 'Z': yaw}. Ключ 'Z' — текущий курс робота в градусах (0…359, 0 = направление инициализации). Это основной источник курса для алгоритмов разворота.
robot.get_laser() Возвращает расстояние до препятствия впереди в сантиметрах. None или 0 — нет данных / ничего не видно в зоне действия. Используется в командах «до упора» и для аварийной остановки в режиме «осторожно».
robot.get_color() Цветовой датчик снизу/спереди (если установлен). Возвращает RGB-кортеж или строку с распознанным цветом — используется для слежения по линии.

Одометрия. У 1T REX нет встроенного GPS, позицию (x, y) робота приходится считать самим: курс берем с гироскопа, пройденное расстояние — из power × time. В сгенерированном Python-коде есть класс Odometry, который делает это автоматически — можно копировать на железо как есть.

Световой индикатор (RGB)

КомандаОписание
robot.set_rgb(idx, (r, g, b), count) Зажечь RGB-светодиод. idx — индекс (0 = первый), (r, g, b) — цвет 0…255 на канал, count — сколько светодиодов подряд от idx в эту команду (обычно 1, у адресной ленты — больше). (0, 0, 0) = погасить.

Инициализация и подключение

КомандаОписание
robot.start() Запуск Rex-Board: инициализирует моторы, серво, гироскоп. Вызывается один раз при старте программы (в нашем симуляторе делается автоматически на сервере, в коде не появляется).
robot.enable_mpu() Включает гироскоп / акселерометр. Без этой команды robot.get_angle() может вернуть нули.

Подключение к плате. 1T REX поднимает Wi-Fi и слушает TCP/WebSocket на порту 8765. Первоначальная настройка Wi-Fi — через USB Type-C + утилита server.py из комплекта робота. Адрес и порт реального робота задаются в настройках в разделе «Соединение».

Готовые функции

В сгенерированном Python-коде уже определены готовые функции, которые собирают сложные алгоритмы из примитивов выше. Их можно копировать на реальный робот как библиотеку — каждая функция написана только через robot.* примитивы, ничего внешнего не требуется. Подробное описание с диаграммами — на вкладке Маневры.

Утилиты

ФункцияЧто делает
duration_for_distance(distance_cm, power_pct) Сколько секунд держать мотор включённым на заданной мощности, чтобы покрыть указанное расстояние. Опирается на калибровку SPEED_CM_PER_S_AT_100.
class Odometry / odo Простой трекер позиции (x, y, heading) через интегрирование power × time + коррекция курса гироскопом (odo.sync_heading()). Метод odo.move_step(power, duration, steer_deg) надо вызывать ПОСЛЕ каждого robot.move(...).

Базовые движения

ФункцияЧто делает
forward_to_wall_cmd(power_pct=DEFAULT_SPEED, stop_margin_mm=150) Движение вперёд до препятствия по дальномеру. Останавливается когда robot.get_laser() вернёт ≤ stop_margin_mm.
backward_to_wall_cmd(power_pct=DEFAULT_SPEED, stop_margin_mm=150) Зеркальная функция — движение назад до препятствия (если есть задний дальномер; иначе по одометрии).

Развороты и ориентация

ФункцияЧто делает
turn_around_cmd(direction=1, power_pct=DEFAULT_SPEED) Разворот на 180° одной K-turn-парой (вперёд по дуге + назад по зеркальной дуге). Робот возвращается ≈ в исходную точку. direction = +1 направо, −1 налево.
turn_around_place_cmd(steps, power_pct=DEFAULT_SPEED) Разворот на месте N парами «вперёд+право → назад+лево» (≈ 30°/пара). 6 пар = 180°. Удобен в тесном пространстве.
face_cardinal_cmd(target_deg, power_pct=DEFAULT_SPEED) Повернуться лицом к указанному курсу (3-дуговой K-turn по формулам Reeds-Shepp: 2α + β = |Δh|, sin(β/2) = sin(|Δh|/2)/2 — робот возвращается в исходную позицию).
set_course_cmd(target_deg, power_pct=DEFAULT_SPEED) Выйти на нужный курс плавной дугой на ходу (без разворота на месте). P-регулятор по углу руля.

Маневры по траектории

ФункцияЧто делает
circle_cmd(direction=-1, power_pct=DEFAULT_SPEED, full_turn_sec=4.0) Один полный круг при максимальном угле руля. По умолчанию CCW (против часовой); direction=+1 — по часовой.
figure_eight_cmd(direction=-1, power_pct=DEFAULT_SPEED, full_turn_sec=4.0) Восьмёрка: первый круг при руле direction × max, второй — в зеркало. Касание двух кругов в одной точке.
spiral_cmd(direction=-1, ..., steer_from=36, steer_to=24, turns=2, micro_sec=0.3) Архимедова спираль: за каждый микро-шаг угол руля меняется линейно от steer_from до steer_to. from > to → раскручивается, from < to → скручивается.
bypass_cmd(start_dir=1, max_steer=36, power_pct=DEFAULT_SPEED, quarter_sec=0.5) Объезд препятствия S-волной из 4 четверть-дуг. После выполнения робот снова на исходной линии движения.

Навигация по координатам

ФункцияЧто делает
goto_cmd(target_x, target_y, power_pct=DEFAULT_SPEED, tolerance_cm=5) Перейти в координату. Shortcut: |bearing| ≤ 30° — едем сразу вперёд, ≥ 150° — задом без разворота, иначе K-turn + прямая. Использует closed-loop коррекцию курса по гироскопу.
home_cmd(power_pct=DEFAULT_SPEED) Возврат в стартовую точку. Эквивалент goto_cmd(START_X_CM, START_Y_CM).
drive_to_point_closed_loop(target_x, target_y, power_pct, tolerance_cm, step_sec=0.1, kp=0.7) Прямой проезд к точке короткими шагами с подруливанием по гироскопу на каждом такте. Если робота сбило — на следующем такте курс будет автоматически скорректирован.
follow_path_cmd(points, power_pct=DEFAULT_SPEED, lookahead_cm=None, tolerance_cm=5) Pure-pursuit за списком waypoint'ов. Каждые 100 мс находит точку впереди на lookahead_cm, рулит к ней. Используется для безопасного обхода зон в режиме «осторожно».

Зоны обстановки

ФункцияЧто делает
mark_danger_cmd(x, y, radius) Отметить опасную (красную) зону по координатам, без движения робота.
mark_danger_here_cmd() Отметить опасную зону под текущей позицией робота (robot.get_gps()).
set_algorithm_zone_cmd(target_x, target_y, radius) Доехать в точку (через goto_cmd) и пометить там жёлтую алгоритмическую зону (часть алгоритма, не обстановки).
remove_zone_cmd(x, y) Удалить зону любого типа, в которую попадает точка.
remove_zone_here_cmd() Удалить зону под текущей позицией робота.

Минимальный пример программы

import math, time

# Едем 100 см вперёд на 40% мощности
duration = 100 / (80 * 40 / 100)   # SPEED_CM_PER_S_AT_100 × power / 100
robot.set_angle(0)
robot.move(40, duration)
robot.stop()

# Поворачиваем руль вправо на максимум и описываем дугу
robot.set_angle(36)
robot.move(40, 2.5)
robot.stop()
robot.set_servo_center()

# Включаем зелёный светодиод
robot.set_rgb(0, (0, 255, 0), 1)

Расширенный пример программы

Полная мини-миссия «прибыл — осмотрелся — поработал — вернулся», использующая максимальный ассортимент robot.*-примитивов: инициализация, мотор/руль, дальномер, гироскоп, цветовой датчик, RGB-индикатор, пауза. Без высокоуровневых обёрток — только примитивы из этого справочника. 

import math, time

# ── 1. Инициализация платы ──────────────────────────────────────────────
robot.start()                                # запуск моторов и сервоприводов
robot.enable_mpu()                           # включаем гироскоп / акселерометр
robot.set_servo_center()                     # руль в нейтраль
robot.set_rgb(0, (255, 200, 0), 1)           # жёлтый = «готов к работе»
time.sleep(0.5)                              # короткая пауза перед стартом

# ── 2. Запоминаем стартовый курс (потом вернёмся на него) ───────────────
start_yaw = robot.get_angle()['Z']           # курс с гироскопа в градусах
print("Стартовый курс:", start_yaw)

# ── 3. Едем вперёд до препятствия с проверкой дальномера ────────────────
robot.set_rgb(0, (0, 255, 0), 1)             # зелёный = «движение»
robot.set_angle(0)                           # руль прямо
robot.move(50)                               # вперёд 50% без duration
while True:
    dist = robot.get_laser()                 # дальность в мм до препятствия
    if dist is not None and dist <= 200:     # ближе 20 см — стоп!
        break
    time.sleep(0.05)                         # 50 мс между опросами
robot.stop()                                 # остановка перед препятствием
robot.set_rgb(0, (255, 0, 0), 1)             # красный = «препятствие!»
time.sleep(0.5)

# ── 4. Считываем цвет под роботом (для слежения по линии) ───────────────
color = robot.get_color()                    # RGB-кортеж или строка-метка
print("Цвет под роботом:", color)

# ── 5. Объезд препятствия — S-волна 4 четверть-дугами ───────────────────
robot.set_rgb(0, (0, 100, 255), 1)           # синий = «маневр объезда»
QUARTER_SEC = 0.5
for phase in range(4):
    sign = +1 if phase in (0, 3) else -1     # 0,3: вправо;  1,2: возврат
    robot.set_angle(sign * 36)               # руль на полный угол
    robot.move(40, QUARTER_SEC)              # проехать четверть дуги
robot.stop()
robot.set_servo_center()

# ── 6. Едем 1 метр прямо ────────────────────────────────────────────────
SPEED_CM_S_100 = 80.0
power = 40
distance = 100
duration = distance / (SPEED_CM_S_100 * power / 100)   # ≈ 3.13 с
robot.set_angle(0)
robot.move(power, duration)
robot.stop()

# ── 7. Описываем полный круг (одна непрерывная дуга 360°) ──────────────
robot.set_angle(-36)                         # руль на максимум (CCW)
robot.move(40, 4.0)                          # ≈ 4 секунды на полный оборот
robot.stop()
robot.set_servo_center()

# ── 8. Возвращаемся на исходный курс мелкими дугами ────────────────────
target_yaw = start_yaw                       # вернуться к стартовому курсу
while True:
    cur = robot.get_angle()['Z']
    diff = ((target_yaw - cur + 540) % 360) - 180   # знаковая невязка
    if abs(diff) < 3.0:                            # допуск ±3°
        break
    direction = +1 if diff > 0 else -1
    robot.set_angle(direction * 36)                 # руль вправо/влево
    robot.move(direction * 30, 0.3)                 # короткий поворот
    time.sleep(0.1)
robot.stop()
robot.set_servo_center()

# ── 9. Едем задним ходом 30 см ──────────────────────────────────────────
duration = 30 / (SPEED_CM_S_100 * power / 100)
robot.move(-power, duration)                  # минусовая мощность = задний ход
robot.stop()

# ── 10. Финиш: пауза, мигающий индикатор, выключение света ─────────────
for _ in range(3):
    robot.set_rgb(0, (0, 255, 0), 1)          # зелёный
    time.sleep(0.3)
    robot.set_rgb(0, (0, 0, 0), 1)            # погасить
    time.sleep(0.3)
robot.set_rgb(0, (0, 0, 0), 1)                # окончательно гасим

Что использовано: robot.start, robot.enable_mpu, robot.set_angle, robot.set_servo_center, robot.move (с duration и без; вперёд и назад), robot.stop, robot.get_angle (yaw), robot.get_laser, robot.get_color, robot.set_rgb (несколько цветов и моргание), time.sleep.
