🛠 Настройка ESP32 (1Т REX) — Web Serial

Эта страница прошивает в EEPROM ESP32 параметры WiFi и адрес моста. Использует Web Serial API прямо в браузере — не нужны ни esp_config.py, ни Python на хосте, ни отдельная программа. Работает в Chrome / Edge (другие браузеры пока не поддерживают Web Serial — для них есть запасной python esp_config.py).

Параметры

IP сервера — это IP компьютера с запущенным bridge.py. ESP32 будет к нему стучаться по WiFi. Запиши IP, по которому твой ПК виден в сети телефона/роутера (например 192.168.88.55).

Порт не выбран. Жми «Подключиться к ESP32».
